# API Testing: Mobile Bank Service

Проект по автоматизации тестирования API банковского сервиса. Основная цель — отработка навыков работы с RestAssured, валидация JSON-схем и настройка CI/CD пайплайнов.


## Описание проекта
В рамках проекта реализовано автоматизированное тестирование REST API мобильного банка. Проект демонстрирует умение работать с HTTP-запросами, проверять структуру ответов сервера и обеспечивать непрерывную интеграцию кода.

## Стек технологий
- **Язык:** Java 11
- **Тестовый фреймворк:** JUnit 5
- **Библиотеки:**
    - RestAssured (тестирование API)
    - JSON Schema Validator (валидация контрактов API)
- **Сборщик:** Gradle
- **CI/CD:** GitHub Actions

## Ключевые реализованные задачи
1. **Валидация контрактов:** Написаны тесты, проверяющие соответствие ответа сервера заранее описанной JSON-схеме (проверка типов данных, обязательных полей и ограничений на значения, таких как валюта `RUR`/`USD`).
2. **CI/CD интеграция:** Настроен пайплайн в GitHub Actions. Сборка автоматически запускается при каждом `push` в репозиторий.
3. **Контроль качества:** Настроены сценарии, при которых сборка падает в случае нарушения логики тестов или несоответствия API-ответа схеме, что обеспечивает контроль качества кода на ранних этапах.
